# BIOS Settings Modifier

## Overview

BIOS Settings Modifier is a Windows desktop utility written in Python that updates option selections inside a text NVRAM configuration script exported by AMISCE (`SCEWIN`).

When AMISCE exports a system's NVRAM script (commonly named `nvram.txt`), the resulting text file can contain thousands of lines and multiple occurrences of the same setting name across different firmware menus. Manually searching the file and moving the `*` selection marker for each setting is slow and error-prone.

This application reads a plain-text settings list containing the setting names and hexadecimal option values you want to select, finds every matching `Setup Question` block in your exported NVRAM script, moves the `*` marker to the requested option value where available, and writes the updated script to a new file.

## Important Limitations

Please read these points before using the tool:

- **Does not write to BIOS firmware directly:** This application only edits a text file exported from SCEWIN. Saving a modified file on disk does not change any settings on your motherboard.
- **Does not execute SCEWIN:** The Python application does not run `SCEWIN_64.exe`, `Export.bat`, or `Import.bat`. Exporting the initial `nvram.txt` file and importing a modified file back into firmware are separate steps performed outside this program.
- **Text exports only:** The tool operates on text script files generated by `SCEWIN_64.exe /o /s nvram.txt`. It does not edit raw binary BIOS images (`.bin`, `.rom`, `.cap`) or raw binary NVRAM dumps.

## Requirements

- **Operating System:** Windows 10 or Windows 11 (required if you also use the bundled 64-bit `SCEWIN` utilities to export or import NVRAM scripts; the Python script editor itself runs on any desktop platform with Python and Tkinter).
- **Python:** Python 3.9 or newer with standard `tkinter` support installed (included by default in the standard Windows Python installer).
- **External Dependencies:** None. The application uses only the Python standard library.
